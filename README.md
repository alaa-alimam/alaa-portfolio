# Alaa Ahmed Al Imam — AI Engineer Portfolio

Premium personal portfolio website for Alaa Ahmed Al Imam.

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React

## Features

- Premium AI-focused visual design
- Responsive layout
- Glassmorphism
- CSS-based 3D AI visual
- Scroll reveal animations
- Interactive project cards
- Testimonial gallery
- Testimonial lightbox
- Responsive mobile navigation
- Contact form with mail client integration
- SEO metadata
- Accessibility support
- Reduced-motion support
